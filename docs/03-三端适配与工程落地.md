# 03 · 三端适配与工程落地

## 0. 动手前必须先确认的一件事

**在 UOS 机器上执行 `uname -m`**：

| 输出 | 结论 |
|---|---|
| `x86_64` | ✅ Flutter Linux 直接可用 |
| `aarch64` | ✅ Flutter Linux 可用（飞腾/鲲鹏机型） |
| `loongarch64` | ❌ **Flutter 无官方支持** → 走 §4 降级方案 |
| `mips64` | ❌ 同上 |

UOS 20（1070）基于 Debian 10，**glibc 2.28**。所有原生产物（Flutter engine、Rust `.so`、PDFium）必须 **≤ glibc 2.28** 构建，否则 `GLIBC_2.29 not found`。这是本项目最大的单点风险，**必须先在 Debian 10 容器里验证**。

## 1. Android

| 项 | 配置 |
|---|---|
| minSdk / targetSdk | 26 / 34 |
| ABI | `arm64-v8a` 主，`armeabi-v7a` 备（用 `flutter build apk --split-per-abi`） |
| Kotlin / Gradle | AGP 8.x，JDK 17 |

**要点**

1. **分区存储（Scoped Storage）**：导入走 **SAF**（`ACTION_OPEN_DOCUMENT`，支持多选），复制进 `getExternalFilesDir()` 后自行管理，**不申请 `MANAGE_EXTERNAL_STORAGE`**（上架会被拒）。
2. **后台同步**：`WorkManager` 周期任务（最小 15 分钟）+ 前台阅读时事件触发。不要用前台服务常驻，耗电且需额外权限。
3. **Rust 产物**：`cargo ndk -t arm64-v8a -t armeabi-v7a -o ../app/android/app/src/main/jniLibs build --release`；在 `build.gradle` 里把 `.so` 打进 `jniLibs`。
4. **阅读体验**：
   - `wakelock_plus` 保持常亮；
   - 音量键翻页（`HardwareKeyboard` + 平台通道兜底）；
   - 手势：左右滑翻页（与漫画的双指缩放冲突 → 漫画模式用 `PageView` + `PhotoView` 手势优先）；
   - 沉浸式：`SystemChrome.setEnabledSystemUIMode(edgeToEdge)`。
5. **字体**：内置思源宋体子集（常用 3500 字 ≈ 2.1MB）避免各 ROM 缺字，用户可换系统字体。
6. **安装包控制**：`--obfuscate --split-debug-info`；PDFium 体积大（~6MB/ABI），考虑做成按需下载的动态特性模块。

## 2. Windows 10

| 项 | 配置 |
|---|---|
| 最低版本 | Windows 10 1809（Flutter Win32 要求） |
| 工具链 | VS 2022 Build Tools（MSVC） |
| 打包 | `msix`（商店/侧载）或 `flutter_distributor` → `Inno Setup` |

**要点**

1. **窗口**：`window_manager` 记住尺寸/位置/最大化状态；支持多实例打开（书架 + 阅读器分离窗口）。
2. **文件关联**：安装时注册 `.epub/.mobi/.cbz/.pdf`；单实例通过 `single_instance` 插件把命令行参数转发给已运行实例 → 直接打开书籍。
3. **Rust 产物**：`cargo build --release --target x86_64-pc-windows-msvc` → `inksync_core.dll` 复制到 `windows/runner/`。也可用 `cargo-xwin` 在 Linux/macOS 上交叉编译（CI 友好）。
4. **PDFium**：`pdfrx` 在 Windows 需要 `pdfium.dll`，从 `pdfium-render` 的 crate 里取预编译产物或自行构建，放到 exe 同目录。
5. **字体**：中文默认 `Microsoft YaHei UI`；安装包可选捆绑思源宋体。
6. **性能**：老机器（集显 + 机械盘）用 `--disable-gpu` 反而不一定更快，**提供开关让用户自选**；禁用 Flutter 的 `Impeller` 回退到 Skia 的开关也保留。
7. **高 DPI**：Flutter Win32 原生支持 Per-Monitor V2，注意自定义绘制的圆角高亮要按 `devicePixelRatio` 走。

## 3. 统信 UOS 20（1070 / kernel 4.19）

### 3.1 运行期依赖

```bash
sudo apt install libgtk-3-0 libblkid1 liblzma5 libjsoncpp1 libsecret-1-0
# 构建期还需：
sudo apt install clang cmake ninja-build pkg-config libgtk-3-dev liblzma-dev libsecret-1-dev
```

### 3.2 构建环境（glibc 2.28 是硬约束）

**推荐：在 Debian 10 容器里构建**，而不是在 UOS 上装工具链（政企机通常不允许）：

```bash
docker run -it --rm -v $PWD:/src -w /src debian:10-slim bash -c '
  apt-get update && apt-get install -y clang cmake ninja-build pkg-config \
      libgtk-3-dev liblzma-dev libsecret-1-dev curl git
  # Flutter / Rust 自行安装
  cd core && cargo build --release --target x86_64-unknown-linux-gnu
  cd ../app && flutter build linux --release
'
```

Rust 侧若不想用容器，可用 `cargo zigbuild --target x86_64-unknown-linux-gnu.2.28`（自动按 glibc 版本链接）。

> **注意**：Flutter 官方 Linux engine 也是按 Ubuntu 20.04（glibc 2.31）构建的预编译产物，但在 Debian 10 上实测可用的前提是 engine 未用到更新的符号。需在 M1 阶段就做一次 `ldd --version` + 实际启动验证，**这是必须前置验证的风险项**。若不可用，只能从源码构建 Flutter engine（约 2 小时/次），或改用 AppImage 自带较新 glibc。

### 3.3 打包为 `.deb`

```
inksync_1.0.0_amd64/
├── DEBIAN/control
├── opt/inksync/{inksync, lib/, data/}
└── usr/share/applications/inksync.desktop
    usr/share/icons/hicolor/{256x256,scalable}/apps/inksync.png
```

`DEBIAN/control`：

```
Package: inksync
Version: 1.0.0
Section: utils
Priority: optional
Architecture: amd64
Depends: libgtk-3-0, libblkid1, liblzma5, libjsoncpp1, libsecret-1-0
Maintainer: your-team <t@example.com>
Description: 三端同步的漫画/小说阅读器
```

`.desktop`（UOS 启动器按 `Categories` 分类）：

```ini
[Desktop Entry]
Type=Application
Name=InkSync
Name[zh_CN]=墨阅
Exec=/opt/inksync/inksync %f
Icon=inksync
Terminal=false
Categories=Office;Viewer;Utility;
MimeType=application/epub+zip;application/x-mobipocket-ebook;application/pdf;application/vnd.comicbook+zip;
```

> **UOS 应用商店上架**：需要《统信 UOS 应用开发规范》合规（不写入系统目录、不使用 root、图标规范、卸载干净）、开发者账号与签名。若只内部分发，直接 `dpkg -i` 即可。

### 3.4 UOS 专属的坑（都是真踩过的）

1. **中文输入法**：Flutter Linux 走 GTK `IMContext`。必须在启动脚本里显式导出，否则**切不出中文**：
   ```sh
   #!/bin/sh
   export GTK_IM_MODULE=fcitx      # UOS 20 默认 fcitx；若为 ibus 则改 ibus
   export QT_IM_MODULE=fcitx
   export XMODIFIERS=@im=fcitx
   exec /opt/inksync/inksync "$@"
   ```
   更稳的方式：检测 `$XDG_SESSION_DESKTOP` / 进程列表自动选择。
2. **字体 fallback**：UOS 自带思源黑体/文泉驿，但部分精简版缺字。App 内置一份思源宋体子集，并在 `ThemeData(fontFamilyFallback: [...])` 里注册。
3. **高 DPI / 缩放**：UOS 的 `GDK_SCALE` 与 Flutter 的 devicePixelRatio 会叠加导致界面过大。启动时读取 `gsettings get org.ukui.SettingsDaemon.plugins.xsettings scaling-factor`（UKUI）做校正。
4. **托盘图标**：UKUI/Deepin 对 `AppIndicator` 支持不一，后台同步建议**用窗口隐藏 + 状态栏**，不依赖托盘。
5. **文件路径**：用户导入走 `xdg-desktop-portal` 文件选择器（`file_selector` 插件在 Linux 走 GTK 原生选择器，OK）；国内路径常见中文，注意 `GLib.filename_to_uri` 编码。
6. **HOME 权限**：不要写 `/opt`（只读），配置与缓存放 `$XDG_DATA_HOME/inksync`、`$XDG_CACHE_HOME/inksync`。

## 4. 降级方案（当 UOS 是 loongarch64 / mips64）

Flutter 无法运行时，**不要重写业务逻辑**，改为换 UI 层：

```
复用：Rust core（解析 + 同步 + HLC + 合并）        ← 100% 复用，Rust 有 loongarch64 target
     SQLite 数据库 schema                          ← 100% 复用
重写：UI 层 → Qt 5.11（UOS 系统自带）/ Qt 6 + QML
     阅读器排版 → QTextDocument / 自绘
```

工作量约 4~5 周。这也正是**把解析与同步放进 Rust、而不是写进 Dart** 的核心收益——它让"UI 层可替换"。

## 5. CI / CD

```yaml
# .github/workflows/build.yml（节选）
jobs:
  android:
    runs-on: ubuntu-latest
    steps: [cargo-ndk → flutter build apk --split-per-abi]
  windows:
    runs-on: windows-latest
    steps: [cargo build --target x86_64-pc-windows-msvc → flutter build windows → msix]
  linux:            # 关键：用 debian:10 容器保证 glibc 2.28
    runs-on: ubuntu-latest
    container: debian:10-slim
    steps: [cargo build → flutter build linux → dpkg-deb --build]
  test:
    steps:
      - cargo test
      - flutter test
      - 集成测试：docker run wsgidav（WebDAV 服务端）→ 跑同步往返测试
```

**集成测试用 `wsgidav`**（Python，支持完整 WebDAV 方法），三个虚拟节点并发读写同一目录，断言最终一致。

## 7. 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| **UOS glibc 2.28 与 Flutter 预编译 engine 不兼容** | 中 | 高 | M1 立即验证；备选：自编 engine / AppImage 自带 glibc |
| UOS 为 loongarch64 | 中 | 高 | §4 降级方案（Qt + 复用 Rust core） |
| `mobi` crate 对某些 HUFF-CDIC 文件失败 | 中 | 中 | 兜底：解析失败时降级为"按 PDB 记录抽取明文 + 提示用户转 EPUB"；收集样本反哺 |
| CBR 无解码器 | 高 | 低 | 一键转 CBZ |
| WebDAV 服务端能力差异 | 高 | 中 | 能力探测（OPTIONS `Allow:`）+ 降级矩阵 |
| PDFium 在 UOS 上缺依赖 | 中 | 中 | 构建时 `ldd` 检查；备选 `mupdf` 静态链接 |
| 大文件同步耗时长 | 中 | 中 | 后台队列 + 进度 UI + 仅 WiFi 选项 |
